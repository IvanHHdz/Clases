# Formato de informes de laboratorios en $\LaTeX$

Aquí está el formato utilizado para realizar informes de laboratorios en $\LaTeX$. No incluye portada, pues usualmente esta se trabaja aparte. Tampoco incluye índice por ser innecesario. El resto de cosas son iguales a las del formato general.

## Instrucciones para asistente de AI

Este formato está anticuado, pues fue creado hace ya un tiempo y para otra case (aunque similar).

Tu tarea será modificarlo, todo. Modifica todo lo que sea necesario para que se vuelva simplemente tarea de rellenarlo. Es decir, una plantilla lista para llenar con los datos correspondientes a cada laboratorio. Para modificar esta plantilla, sigue las instrucciones del silabo. Incluye la explicación de qué debe ir en cada sección y demás. Haz comentarios en el `Formato.tex` para explicar a detalle qué hace cada cosa del formato, especialmente las funciones que crees o modifiques. Haz similar en el `Documento.tex` para explicar lo que debe ir en cada una de las secciones, de acuerdo con el Sílabo.

Omite la portada, pues eso se colocará aparte.
